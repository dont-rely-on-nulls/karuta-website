#+begin_pillar
{{{eyebrow(Kernel)}}}
{{{h3(Relations\, not tables)}}}

Sakura is a subsystem leveraging the RNT kernel; a Windows-NT-inspired kernel built using *relations*.
Sakura may interact with other RNT-based subsystems in the future.
#+end_pillar

#+begin_pillar
{{{eyebrow(One language)}}}
{{{h3(Everywhere)}}}

Shared *syntax* for the language entities that are *semantically* the same.
Karuta being embeddable in RNT is planned! Stored procedures are coming!
#+end_pillar

#+begin_pillar
{{{eyebrow(Database)}}}
{{{h3(Properties)}}}

Persisted data is *finite*. Hence, *totality* can be exploited. The more guarantees the better.
A database that halts makes the world a better place.
#+end_pillar

#+begin_src karuta
% entry point
factorial[X, Out] :-
  karuta:nat[X],
  'factorial loop'[X, 1, Out].

% arity overloading
'factorial loop'[0, Out, Out] :- karuta:nat[Out].
'factorial loop'[N, Acc, Out] :-
  karuta:nat[N],
  karuta:mult[N, Acc, NewAcc],
  karuta:minus[N, 1, Prev],
  'factorial loop'[Prev, NewAcc, Out].

% query with conjuction
factorial[5, Out1], factorial[6, Out2]?
#+end_src

A logic language for the BEAM.
#+end_h2

State facts, write constraints, ask questions. Karuta finds the answers with unification and search, on application or database, and
runs them on the BEAM via Kanren primitives.

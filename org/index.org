#+begin_intro
#+begin_h2
This is Karuta.\\
A logic language for the BEAM.
#+end_h2

State facts, write rules, ask questions. Karuta finds the answers with unification and search, and runs them on the same virtual machine as Erlang and Elixir.

#+begin_section .pillars #docs

#+begin_pillar
{{{eyebrow(Declare)}}}
{{{h3(Facts and rules)}}}

Describe what is true and let the engine search for what follows. Pattern matching, unification and backtracking come built in.
#+end_pillar

#+begin_pillar
{{{eyebrow(Run)}}}
{{{h3(On the BEAM)}}}

Processes, supervisors and hot code loading work the way you know them. Call Erlang and Elixir modules from a rule with ~call/3~.
#+end_pillar

#+begin_pillar
{{{eyebrow(Keep)}}}
{{{h3(Sakura beside it)}}}

Store facts in Sakura, Karuta's partner database, and query them with the same rules you already wrote. {{{a(/sakura.html,Meet Sakura)}}}.
#+end_pillar

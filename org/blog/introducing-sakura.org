Sakura stores relations for Karuta programs. You declare a relation once and every fact asserted into it is kept across restarts.

Because Sakura speaks Karuta, there is no separate query language. A rule that reads in-memory facts reads stored ones the same way. {{{a(/sakura.html,Read more about Sakura)}}}.

#+TITLE: Running every query branch as a process
#+DATE: 2026-08-28
#+FILETAGS: :Internals:
#+DESCRIPTION: What changes when search can use the whole BEAM scheduler.
#+KANA: つばさ
#+SAMPLE: yes
#+OPTIONS: toc:nil title:nil

A search tree has branches that do not depend on each other. On the BEAM, independent work is what processes are for.

Karuta can hand separate branches to separate lightweight processes. Each one is supervised, so a branch that fails does not take the whole query down.
